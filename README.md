# archcst Homebrew Tap

## Popeste

Native menu bar utility for reusable phrases. Requires Apple Silicon and macOS 14+.

```sh
brew tap archcst/tap
brew install --cask popeste
```

**The current release is an unnotarized test build.** macOS may block its first launch. Read the [release notes](https://github.com/archcst/popeste/releases) before installing. Homebrew does not bypass Gatekeeper.

```sh
brew upgrade --cask popeste
brew uninstall --cask popeste
```

Uninstalling retains your data in `~/.config/popeste`.
